# Or Paull Photography - Project Context

## Project Overview

Building a professional web application for Or Paull Photography—a photography service business featuring:
- **Portfolio Gallery**: Showcase past work across categories (weddings, portraits, events, etc.)
- **Booking System**: Allow clients to request and book photography services
- **Service Packages**: Display different photography packages and pricing
- **Client Management**: Track inquiries, bookings, and customer relationships
- **Admin Dashboard**: Manage portfolio, bookings, payments, and analytics

## Business Goals

1. **Attract Clients**: Showcase photography portfolio professionally
2. **Streamline Bookings**: Automated scheduling and client communication
3. **Manage Services**: Organize packages, pricing, and availability
4. **Process Payments**: Secure payment processing for bookings
5. **Build Relationships**: Track and maintain client communications

## Technical Stack Preferences

- **Frontend**: Modern, minimal code (ponytail principles)
- **Design**: Professional, distinctive (Taste framework)
- **Backend**: Efficient architecture with multi-agent support
- **Security**: High-priority for payment and customer data
- **Scalability**: Support growth without over-engineering

## Integrated Skills Usage

### 1. Task Decomposer
**When**: Planning phase
**Purpose**: Break project into phases and deliverables
**Output**: Detailed task list with dependencies

### 2. Grill-Me
**When**: After task decomposition
**Purpose**: Validate all requirements and design decisions
**Output**: Resolved ambiguities, confirmed feature scope

### 3. Find-Skills
**When**: During architecture phase
**Purpose**: Discover optimal libraries and frameworks
**Output**: Recommended tech stack components

### 4. Taste Framework
**When**: UI/UX design phase
**Purpose**: Create professional, distinctive design
**Output**: Design system and component guidelines

### 5. CrewAI
**When**: Development phase (optional multi-agent approach)
**Purpose**: Orchestrate complex development workflows
**Output**: Autonomous agents for portfolio, booking, payment, admin

### 6. Ponytail
**When**: Throughout development
**Purpose**: Enforce minimal, efficient code
**Output**: Reduced complexity, lower API costs

### 7. Bug-Hunter
**When**: QA and pre-launch phase
**Purpose**: Security audit and vulnerability scanning
**Output**: Security fixes, vulnerability reports
